# portfolio-sarah

Portfolio de Sarah Beets, community manager freelance et stratège en communication digitale basée dans le Loiret, à une heure de Paris. Communication, création de contenus et réseaux sociaux.

Le site est entièrement statique (HTML, CSS et JavaScript) et se publie tel quel avec GitHub Pages. La page d'accueil est `index.html` et tous les visuels, les reels et les polices sont rangés dans le dossier `assets`.

## Mettre le site en ligne avec GitHub Pages

Dans l'onglet Settings du dépôt, ouvrir Pages puis choisir « Deploy from a branch » avec la branche `main` et le dossier `/ (root)`. Une ou deux minutes plus tard le site est visible à l'adresse https://mausa30103010.github.io/portfolio-sarah/

## Changer un visuel ou une vidéo

Remplacer le fichier dans `assets/img` ou `assets/video` en gardant exactement le même nom. Pour une vidéo, remplacer aussi l'image d'aperçu `.webp` qui porte le même nom.
